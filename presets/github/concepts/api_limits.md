# GitHub API — лимиты и паттерны

Текст для `concept_add` (без секретов).

## Rate limiting

- REST: заголовки `X-RateLimit-Remaining`, `X-RateLimit-Reset`.
- При `403` с abuse/limit — снизить частоту, использовать условные запросы `If-None-Match`.

## Аутентификация

- Передавать PAT в заголовке `Authorization: Bearer <token>` (поддерживается для PAT).
- Не логировать токен и полные URL с query, содержащие чувствительные данные.

## Типичные ошибки

| HTTP | Причина | Действие |
|------|---------|----------|
| 401 | Неверный или отозванный PAT | Выпустить новый PAT, обновить KV |
| 403 | SSO required (org) | Авторизовать токен для org на GitHub |
| 404 | Нет прав на репозиторий | Расширить scope или доступ fine-grained token |
