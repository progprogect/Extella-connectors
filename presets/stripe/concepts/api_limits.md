# Stripe API — лимиты и паттерны

Текст для `concept_add`.

## Идемпотентность

- Используйте заголовок `Idempotency-Key` для POST, создающих объекты.

## Ошибки

- Разбор `error.type`, `error.code` в JSON ответа.
- `429` — exponential backoff, уважать рекомендации Stripe.

## Безопасность

- Предпочитать **restricted keys** с минимальным списком ресурсов.
- Не логировать полные номера карт и CVC.
