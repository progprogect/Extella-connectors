# `<connector_id>` — лимиты API и устойчивые паттерны

Текст для загрузки в Extella через `concept_add` (без секретов и без персональных данных).

## Rate limits

- Опишите официальные лимиты провайдера (запросов в секунду / минуту / день).
- Рекомендация: экспоненциальный backoff при `429`, уважать заголовок `Retry-After` если есть.

## Типичные ошибки

| Код / симптом | Вероятная причина | Действие |
|---------------|-------------------|----------|
| 401 | Истёк токен или неверный ключ | Обновить KV, пройти OAuth заново |
| 403 | Недостаточно scope | Расширить права у провайдера |
| 429 | Превышен лимит | Подождать, уменьшить частоту вызовов |

## Паттерн вызова из эксперта

- Использовать таймауты HTTP (30–120 с).
- Не логировать тело ответа, если оно может содержать PII.
- Читать секреты только из параметра эксперта (инжект из KV) или из `os.environ`, не хардкодить.
